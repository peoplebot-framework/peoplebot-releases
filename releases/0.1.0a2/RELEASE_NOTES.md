# PeopleBot 0.1.0a2

PeopleBot `0.1.0a2` is a corrective experimental prerelease of Git-native
framework utilities. It supersedes `0.1.0a1` for new downloads.

## Correction

Project-specific documentation was removed from the package and proposed public
materials. The source distribution no longer includes repository working
instructions, private project state, historical handoffs, or consuming-project
planning. Generic sovereign-environment requirements are retained in a public
contract, and every consuming-project identity and operational input remains
caller-supplied.

This is a documentation, package-version, and source-selection correction. Runtime
modules, schemas, defaults, configuration, and test fixtures are unchanged from the
accepted `0.1.0a1` implementation.

## Included capabilities

- deterministic exact Git State resolution;
- bounded context preparation and explicit UTF-8 context assembly;
- Windows environment-local single-Execution admission;
- local admitted-start and terminal Execution provenance;
- explicit local Instance-memory checkpoint and exact resume;
- explicit synchronization and recovery utilities;
- one purpose-specific bounded read-only Adapter; and
- trusted synthetic alpha setup, compatible-adoption, and resume demonstrations.

The release does not create a functioning Architect or project-task agent, provision
a consuming environment, transfer credentials or authority, publish runtime memory,
or provide general migration, messaging, scheduling, UI, or automatic learning.

## Inspection result

The proposed wheel and source archive have safe inventories; matching source,
configuration, and license files; valid generated metadata; a valid wheel `RECORD`;
and no consuming-project name, binding, host-specific path, or inherited control
configuration. All packaged relative documentation links resolve. A fresh isolated
installation passed both CLI help smoke checks.
