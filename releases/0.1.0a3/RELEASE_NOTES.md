# PeopleBot 0.1.0a3

PeopleBot `0.1.0a3` is a candidate experimental prerelease of project-neutral,
Git-native framework utilities. It builds on `0.1.0a2` and adds one genuine
bounded project-review Blueprint and its purpose-specific Codex Adapter.

The project-review operation accepts only caller-supplied pinned context under an
exact context policy. It can return bounded cited findings, a truthful
`no_findings` outcome for an adequate supplied-scope review, or an
`insufficient_evidence` outcome. Protocol conformance does not prove factual
correctness or completeness.

Response validation rejects malformed Unicode while retaining independently known
provider usage, including when terminal evidence persistence later fails.
Blueprint Boolean and integer fields require exact JSON scalar types. The Adapter
reuses the established direct-process and admission/provenance lifecycle without
changing the licensing Adapter protocol.

The package declares no runtime dependencies. It does not create a functioning
Architect, provision a consuming environment, activate an Instance, transfer
credentials or authority, invoke a model during installation, or implement general
migration, messaging, schedules, UI, or automatic learning.

The candidate remains local until its exact public-distribution commit and four
reviewed release assets receive separate publication authorization.
