title: "PeopleBot"
description: "A Git-native foundation for durable agent work."
---

PeopleBot uses Git to give agent work an addressable history: the inputs an execution used, the work it attempted, and the results it saved. Its design separates reusable behavior from individual agents and their saved state.

These guides cover **the public experimental release 0.1.0a3**. Installing it provides framework utilities and a bounded project-review adapter. It does not start an autonomous agent or a scheduled development service.

## Get started

1. [Install the public package](/guides/install) and check the command-line interface.
2. [Check the release capabilities](/guides/capabilities) before choosing a workflow.
3. [Learn the five core concepts](/guides/concepts) to understand how the pieces fit.

The public [release page](https://github.com/peoplebot-framework/peoplebot-releases/releases/tag/v0.1.0a3) provides the package, matching source archive, checksums, and provenance. No private repository access is required.
