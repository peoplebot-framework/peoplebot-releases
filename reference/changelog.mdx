This history is centrally maintained from public release evidence. **Released** means included in a published artifact; it does not mean installed or live-tested on your computer. Dates below are UTC.

## Documentation — October 6, 2026

Added [mobile agent access with Termius](/tutorials/termius-mobile): assistant-guided setup, saved launchers, direct agent conversations, and reconnect checks. Added a [proposed open-source support acknowledgment](/reference/termius-open-source), with official logo placement and an explicit license-eligibility caveat. This documents an operating workflow, not a native integration or an approved sponsorship.

Added the practical human-guided workflow: assigning work, reviewing completion evidence, continuing in a new chat, and verifying backups. Corrected the beginner introduction's stale version, clarified memory versus transcript exports, and replaced command placeholders with the exact a4 distribution commit. These are documentation changes, not a framework release.

## Framework 0.1.0a4 — September 16, 2026

Added experimental Git messaging, finite work and development cycles, corrected Codex diagnostics, and per-Instance usage collection. Includes isolated attempts and exact review inputs. Scheduling remains unconfigured; the release reports no accepted live model invocation and makes no Claude or non-Windows runtime support claim.

[Release and checksums](https://github.com/peoplebot-framework/peoplebot-releases/releases/tag/v0.1.0a4).

## Syslog onboarding 0.1.0 — September 14, 2026

A separate offline helper and instructions for GitHub activity through an operator-managed gateway to project-specific Papertrail TLS destinations. Requires private enrollment and live ingestion verification. This is not a framework runtime upgrade.

[Separate utility release](https://github.com/peoplebot-framework/peoplebot-releases/releases/tag/syslog-onboarding-v0.1.0).

## How this stays accurate

Each new entry should name the component, user-visible change, exact source or release, verification performed, availability, and limitations. Agent reports supply evidence; central documentation review decides what is appropriate to publish. Private machine reports and candidate versions are not public release announcements.
